Flujos Automatizados

Los cuatro flujos principales implementados para Narosa Sweet Party, ordenados por impacto y prioridad de activación.

🛍️
P1WhatsApp

Flujo 1 — Consulta de Producto

Cliente pregunta por un producto → n8n llama Shopify API → Claude genera respuesta con precio y stock → WhatsApp envía respuesta inmediata 24/7.

Webhook WA → IF filtro spam → Shopify lookup
Claude haiku-4-5 genera respuesta natural
Respuesta en <3 segundos · 24/7 sin intervención
🎂
P1Lead

Flujo 2 — Presupuesto Decoración

Cliente pide presupuesto para evento → Claude extrae datos (tipo, fecha, personas, presupuesto) → Gmail envía lead calificado a tiendapoblenou@narosasp.com.

Clasificación: DECORACION / COMPRA / INFO / SPAM
Email con datos del evento formateados
Registro en Google Sheets CRM automático
💬
WhatsAppInfo

Flujo 3 — Horarios e Info

Consultas sobre horarios, ubicación, talleres y FAQ → Claude responde con datos actualizados de la tienda. Desvía a humano si la consulta es compleja.

InstagramMeta API

Flujo 4 — Instagram DM

DM entrante en @narosasweetparty → Meta webhook → n8n → Claude → respuesta via Graph API. Misma lógica de clasificación que WhatsApp, aprobación Meta requerida.
