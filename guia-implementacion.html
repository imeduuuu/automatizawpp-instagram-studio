Automatización completa WhatsApp + Instagram para Narosa Sweet Party · Desde cero hasta sistema funcionando · 21 días

Preparación previa · 1-2 días antes de empezar
Cosas que necesitas tener listas antes de instalar nada
0.1
Cuentas y credenciales necesarias
Crea o verifica estas cuentas antes del día 1. Algunas tardan en aprobarse.
Requisito previo
  • Número de teléfono para WhatsApp Business — puede ser el que ya usa Narosa (+34 640 92 16 71) o uno nuevo dedicado. Tener acceso físico al móvil para escanear el QR.
  • Cuenta de Hetzner Cloud (hetzner.com) — tarjeta de crédito/débito para pagar el VPS (~6€/mes)
  • Cuenta de Meta Developers (developers.facebook.com) — con Facebook personal vinculado a la página de negocio de Narosa
  • Cuenta de Instagram Business — @narosasweetparty debe estar en modo "cuenta de empresa" y vinculada a una página de Facebook
  • Cuenta de Anthropic (Claude API) (console.anthropic.com) — para la IA. Añadir saldo mínimo de 10€ para empezar
  • Google Account — para Google Sheets CRM
  • Dominio propio (opcional pero recomendado) — ej: bot.narosasp.com — desde Namecheap, GoDaddy o donde esté el dominio narosasp.com
Importante sobre Instagram

La cuenta @narosasweetparty debe estar en "Cuenta profesional → Empresa" (no Creador). Ir a Instagram → Configuración → Cuenta → Cambiar a cuenta profesional → Empresa. Luego vincularla a la página de Facebook de Narosa en: Facebook → Configuración → Instagram → Conectar cuenta.

0.2
Preparar el catálogo de productos
Lista de productos que la IA necesita conocer para responder consultas
  • Exportar catálogo de Shopify: Admin Shopify → Productos → Exportar → CSV. Tendrás nombre, precio y descripción de cada producto.
  • Crear un archivo catalogo-narosa.json con los productos más consultados (top 50-100 es suficiente para empezar)
  • Incluir: nombre del producto, precio, descripción corta, URL en narosasp.com, si hay stock (sí/no)
Ejemplo formato catalogo-narosa.json
// Estructura mínima recomendada

    "url": "https://narosasp.com/products/kit-unicornio",
    "categoria": "kits-cumpleanos",
    "stock": true

1
Servidor VPS + Infraestructura · Días 1-2 · ~3h
El servidor donde correrá todo el sistema. Solo necesitas hacer esto una vez.
1.1
Contratar VPS en Hetzner
El servidor que alojará Evolution API, n8n y Redis
~6€/meshetzner.com
  • Ir a hetzner.com → Cloud → Nuevo servidor
  • Seleccionar: CX21 (2 vCPU, 4GB RAM, 40GB SSD) — suficiente para todo
  • Sistema operativo: Ubuntu 22.04 LTS
  • Región: Falkenstein o Nuremberg (la más cercana a España)
  • Añadir tu clave SSH o nota la contraseña root que te dan
  • Apuntar el dominio o subdominio (ej: bot.narosasp.com) a la IP del VPS en tu proveedor DNS
1.2
Configurar el servidor (Docker + Nginx + SSL)
Conectar al servidor por SSH e instalar los componentes base
Terminal / SSHCopy-paste
Comandos SSH — ejecutar en orden (copy-paste exacto)
# 1. Conectar al VPS
ssh root@TU-IP-DEL-VPS

# 2. Actualizar el sistema
apt update && apt upgrade -y

# 3. Instalar Docker
curl -fsSL https://get.docker.com | sh
systemctl enable docker && systemctl start docker

# 4. Instalar Docker Compose
apt install docker-compose-plugin -y

# 5. Instalar Nginx
apt install nginx -y
systemctl enable nginx

# 6. Instalar Certbot (SSL gratuito)
apt install certbot python3-certbot-nginx -y

# 7. Crear carpeta del proyecto
mkdir -p /opt/narosa-bot && cd /opt/narosa-bot

Ejecuta: ping bot.narosasp.com y comprueba que responde con la IP de tu VPS. Si no, espera 15-30 min a que propague el DNS.

Obtener certificado SSL (ejecutar cuando el DNS ya apunte al VPS)
certbot --nginx -d bot.narosasp.com

2
Evolution API — WhatsApp · Días 2-3 · ~2h
Conectar el número de WhatsApp de Narosa al servidor para recibir y enviar mensajes automáticamente
2.1
Instalar Evolution API con Docker
La API open source que conecta WhatsApp al sistema
Gratis · Open sourcegithub.com/EvolutionAPI
Crear docker-compose.yml para Evolution API
nano /opt/narosa-bot/docker-compose.yml
# Pegar este contenido:

version: '3.8'
services:
  evolution-api:
    image: atendai/evolution-api:latest
    container_name: evolution_api
    restart: always
    ports:
      - "8080:8080"
    environment:
      - SERVER_URL=https://bot.narosasp.com
      - AUTHENTICATION_API_KEY=TU-CLAVE-SECRETA-AQUI
      - AUTHENTICATION_EXPOSE_IN_FETCH_INSTANCES=true
    volumes:
      - evolution_data:/evolution/instances
      - evolution_store:/evolution/store

  redis:
    image: redis:7-alpine
    container_name: redis
    restart: always
    ports:
      - "6379:6379"

volumes:
  evolution_data:
  evolution_store:
Iniciar los servicios
cd /opt/narosa-bot && docker compose up -d
# Verificar que están corriendo:
docker compose ps
2.2
Configurar Nginx para Evolution API
Proxy inverso para que el webhook sea accesible por HTTPS
Archivo Nginx para evolution API
nano /etc/nginx/sites-available/narosa-bot
# Pegar:

server {
    server_name bot.narosasp.com;
    location / {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
# Activar y recargar:
ln -s /etc/nginx/sites-available/narosa-bot /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
2.3
Conectar el número de WhatsApp (escanear QR)
El momento en que el número de Narosa queda vinculado al bot
Necesitas el móvil con WhatsApp
  • Abrir en el navegador: https://bot.narosasp.com/manager
  • Autenticarse con la API Key que pusiste en el docker-compose
  • Crear nueva instancia: nombre "narosa"
  • En el móvil con el WhatsApp de Narosa: Ajustes → Dispositivos vinculados → Vincular dispositivo
  • Escanear el QR que aparece en pantalla
  • El estado debe pasar a CONNECTED en verde
Importante: el móvil debe permanecer con batería y conexión

El WhatsApp del móvil solo actúa como enlace. Para operación continua, asegúrate de que el teléfono no tenga ahorro de batería activado y tenga wifi o datos. Evolution API actúa como dispositivo vinculado de multi-device, así que el móvil no necesita estar activo constantemente, pero sí encendido y con conexión eventual.

3
n8n — Motor de automatización · Días 3-4 · ~2h
n8n es el cerebro que conecta WhatsApp, la IA, el email y los Google Sheets
3.1
Añadir n8n al docker-compose
n8n se instala en el mismo servidor, junto a Evolution API
Gratis · Open source
Añadir al docker-compose.yml existente (dentro de services:)
  n8n:
    image: n8nio/n8n:latest
    container_name: n8n
    restart: always
    ports:
      - "5678:5678"
    environment:
      - N8N_HOST=n8n.narosasp.com  # o usa bot.narosasp.com/n8n
      - N8N_PROTOCOL=https
      - WEBHOOK_URL=https://n8n.narosasp.com
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD=TU-PASSWORD-SEGURA
    volumes:
      - n8n_data:/home/node/.n8n

# En volumes: añadir:
  n8n_data:
Reiniciar con el nuevo servicio + Nginx para n8n
docker compose up -d n8n

# Configurar Nginx para n8n (en el mismo archivo o uno nuevo):
# Añadir server block para n8n.narosasp.com apuntando a puerto 5678
certbot --nginx -d n8n.narosasp.com
3.2
Crear el flujo principal en n8n (Workflow WhatsApp → IA → Respuesta)
El workflow que recibe mensajes de WA y los procesa con IA
  • Abrir https://n8n.narosasp.com en el navegador → entrar con usuario/contraseña
  • Clic en "New Workflow" → nombrar "Narosa WA → IA → Respuesta"
  • Añadir nodo Webhook: método POST, path /wa-narosa. Copiar la URL del webhook.
  • En Evolution API: configurar webhook → URL: https://n8n.narosasp.com/webhook/wa-narosa, eventos: messages.upsert
  • Añadir nodo IF: filtrar solo mensajes entrantes (no los que envía el bot)
  • Añadir nodo HTTP Request (a Claude API) → ver paso 3.3
  • Añadir nodo HTTP Request (a Evolution API sendMessage) para enviar la respuesta
  • Conectar los nodos en orden: Webhook → IF → Claude → sendMessage
3.3
Configurar la llamada a Claude API (la IA)
Nodo HTTP Request en n8n que llama a Anthropic para generar la respuesta
Claude API key de console.anthropic.com
Configuración del nodo HTTP Request → Claude API en n8n
URL: https://api.anthropic.com/v1/messages
Método: POST
Headers:
  x-api-key: TU-CLAUDE-API-KEY
  anthropic-version: 2023-06-01
  content-type: application/json

Body (JSON):
{
  "model": "claude-haiku-4-5-20251001",
  "max_tokens": 400,
  "system": "Eres Nara, la asistente de Narosa Sweet Party...
             [tu system prompt completo aquí]",
  "messages": [
    {
      "role": "user",
      "content": "{{ $json.body.data.message.conversation }}"
    }
  ]
}
4
Filtro de Leads + Email al equipo · Días 5-6 · ~3h
Identificar clientes con intención de compra y notificar al equipo de Narosa por email
4.1
Añadir nodo de clasificación de intención
Después de que Claude responde, pedirle también que clasifique si el mensaje es un lead
Segunda llamada a Claude API — solo clasificación (muy barata)
# En n8n, añadir un segundo nodo HTTP Request después del de respuesta:
Body:
{
  "model": "claude-haiku-4-5-20251001",
  "max_tokens": 50,
  "messages": [{
    "role": "user",
    "content": "Clasifica este mensaje en: LEAD_DECORACION / LEAD_COMPRA / INFO / SPAM.\nMensaje: {{ $json.body.data.message.conversation }}\nResponde SOLO con la categoría."
  }]
}

# Añadir nodo IF después:
# Si la respuesta contiene "LEAD_DECORACION" → rama lead decoración (email urgente)
# Si contiene "LEAD_COMPRA" → rama lead compra (email normal)
# Si es "INFO" → solo responde, no email
4.2
Configurar envío de email de lead
Usar el nodo Email de n8n o la integración con Gmail
Gmail gratis
  • En n8n: Credenciales → Gmail → conectar con la cuenta de email de Narosa
  • Añadir nodo Gmail → Send Email en la rama de leads
  • Para: tiendapoblenou@narosasp.com
  • Asunto: 🎈 Nuevo lead {{ tipo_lead }} · {{ fecha_hora }}
  • Cuerpo HTML: incluir nombre del contacto, número WA, mensaje original, clasificación y enlace a responder
4.3
Registrar lead en Google Sheets (CRM)
Todos los leads quedan guardados en una hoja de cálculo
  • Crear hoja de cálculo en Google Sheets: columnas → Fecha, Canal, Teléfono, Nombre, Mensaje, Tipo Lead, Estado
  • En n8n: Credenciales → Google Sheets → OAuth con tu cuenta de Google
  • Añadir nodo Google Sheets → Append Row en la rama de leads
  • Mapear cada columna con los datos del webhook de Evolution API
  • Estado inicial: "Nuevo" — el equipo lo cambia manualmente a "Contactado" o "Cerrado"
5
Instagram DM (Meta API) · Días 8-13 · ~5h
Automatizar los DMs de @narosasweetparty. Esta fase requiere aprobación de Meta (2-5 días hábiles)
5.1
Crear app en Meta Developers
La app es el puente oficial entre Instagram y tu servidor
Requiere página Facebook + cuenta empresa IG
  • Ir a developers.facebook.com → Mis Apps → Crear App
  • Tipo: "Empresa" → nombre: "Narosa Bot"
  • Añadir producto: Instagram Graph API y Webhooks
  • En Webhooks → Instagram → Suscribir a: messages, messaging_postbacks
  • URL del webhook: https://n8n.narosasp.com/webhook/ig-narosa
  • Token de verificación: una cadena secreta que tú defines (ej: narosa2026secret)
  • Vincular la página de Facebook de Narosa a la app y generar Page Access Token (permanente)
Tiempo de aprobación de Meta

Las apps de Instagram Messaging necesitan revisión de Meta si quieres enviar mensajes proactivos. Para responder mensajes que el usuario inicia (el caso de Narosa), no necesitas aprobación especial — funciona con app en modo de desarrollo primero. Tras 30 días, solicitar modo producción.

5.2
Crear workflow Instagram en n8n
Similar al de WhatsApp, pero con la API de Meta
Nodo Webhook en n8n para Instagram
Path: /ig-narosa
Método: GET + POST
# GET: para la verificación inicial de Meta (hub.challenge)
# POST: para recibir los mensajes

# Respuesta al GET de verificación (nodo Respond to Webhook):
# Si hub.verify_token === "narosa2026secret" → responder hub.challenge

# Payload POST que llega de Instagram:
{
  entry[0].messaging[0].sender.id    → ID del usuario que escribe
  entry[0].messaging[0].message.text → texto del mensaje
}
Enviar respuesta por Instagram Graph API
URL: https://graph.facebook.com/v19.0/me/messages
Método: POST
Params: access_token=TU_PAGE_ACCESS_TOKEN
Body:
{
  "recipient": { "id": "{{ sender_id }}" },
  "message": { "text": "{{ respuesta_de_claude }}" }
}
6
Flujo de encargo / lead de decoración · Días 7-8 · ~3h
El flujo de mayor valor para Narosa: capturar leads de decoración de eventos (ticket 150-400€+)
6.1
Implementar formulario conversacional con estado
El bot hace preguntas en secuencia para recoger todos los datos del encargo
Lógica de estado conversacional (usando Redis como memoria)
# En n8n, antes de llamar a Claude, consultar estado en Redis:
# Nodo: HTTP Request → GET redis/session/{phone_number}

# States del flujo de decoración:
null         → primera vez, Claude responde normalmente
"dec_fecha"  → esperando la fecha del evento
"dec_tipo"   → esperando tipo y temática del evento
"dec_lugar"  → esperando dónde (domicilio o local)
"dec_nombre" → esperando nombre y teléfono de contacto
"dec_done"   → lead completo → email → reset estado

# Claude recibe el estado y su instrucción cambia según el estado:
system: "Estado actual: dec_tipo. El usuario ya dijo que la fiesta es el 20 de junio.
         Ahora pregúntale cuál es la temática y si es a domicilio o en un local."
Alternativa sin Redis (más simple para empezar)

n8n tiene variables de sesión propias en los workflows. Si el volumen es bajo (<50 conversaciones simultáneas), puedes usar las variables del workflow sin necesidad de Redis. Más adelante se puede migrar.

7
Integración Shopify (stock en tiempo real) · Días 9-11 · ~4h
Conectar narosasp.com al bot para responder preguntas de disponibilidad con datos reales
7.1
Obtener Shopify API key de narosasp.com
Desde el admin de Shopify crear una app privada con acceso de lectura
Solo lectura — no riesgo
  • Admin Shopify → Configuración → Apps → Desarrollar apps → Crear app
  • Nombre: "Narosa Bot"
  • Permisos API Admin (solo lectura): read_products, read_inventory, read_orders
  • Instalar app → copiar Admin API access token
Consulta de producto desde n8n → Shopify API
URL: https://narosasp.com/admin/api/2024-01/products.json?title={{ nombre_producto }}
Headers:
  X-Shopify-Access-Token: TU-SHOPIFY-TOKEN

# La respuesta incluye: precio, stock, descripción, imágenes, URL
# Pasas esa info a Claude como contexto para que responda con datos reales
8
Tests, ajustes y lanzamiento · Días 14-21 · ~6h
Verificar que todo funciona con mensajes reales antes de comunicar a los clientes
8.1
Script de tests — mensajes que debes probar
Envía exactamente estos mensajes al WhatsApp de Narosa desde otro teléfono
  • ✉️ "Hola" → debe responder con bienvenida y menú de opciones
  • 🎈 "¿Tenéis globos de unicornio?" → debe buscar en catálogo y responder con precio y enlace

  • 🎉 "Quiero decorar la fiesta de cumpleaños de mi hijo" → debe iniciar el flujo de lead de decoración y pedir la fecha
  • ⏰ Mensaje a las 22:00 → debe responder aunque sea fuera de horario, con nota de horario
  • 📍 "¿Dónde estáis?" → debe responder dirección + horario
  • 📸 Probar mismo desde Instagram DM a @narosasweetparty
8.2
Checklist de lanzamiento
Verificaciones finales antes de anunciar el sistema
  • Los emails de leads llegan a tiendapoblenou@narosasp.com en <60 segundos
  • Los leads se registran correctamente en Google Sheets
  • El bot responde fuera del horario de la tienda (domingo, noche)
  • Las respuestas de Instagram DM funcionan con la Meta App en modo producción
  • El bot no envía spam si el cliente envía el mismo mensaje dos veces
  • Si el cliente escribe "hablar con persona", el bot escala y avisa al equipo
  • El catálogo de productos está actualizado con los precios correctos
  • Se ha hecho la formación de 1h con el equipo de Narosa
Resultado esperado el día 21

Sistema 100% operativo. WhatsApp de Narosa responde automáticamente 24/7. Los encargos de decoración llegan como leads al email del equipo en <60 segundos. Instagram DMs respondidos en <3 segundos. Coste total del sistema: ~108€/mes.
